`main.ts` (Node 22) writes a single one-line joke about office life — at most 200 characters — to `/output/entry.txt`:

> I renamed my phone's hotspot 'Meeting Room 4' so my team spends the all-hands looking for a room that doesn't exist.

Run it with:

```sh
node main.ts
```
